## 📌 Fitur Utama & Keunggulan

1. **Semantic HTML5 Markup**: Struktur halaman yang inklusif dan mematuhi standar aksesibilitas web (a11y) serta SEO basic.
2. **Custom CSS3 & Dark Mode**: Menggunakan CSS variables untuk mendukung perubahan *Light/Dark Theme* secara mulus dengan penyimpanan preferensi pengguna di `LocalStorage`.
3. **Mobile-First Responsive Design**: Tampilan yang dioptimalkan untuk perangkat Mobile, Tablet, hingga Desktop menggunakan Flexbox dan CSS Grid.
4. **Interactive JavaScript Controls**:
   - **Custom Mouse Cursor**: Kursor khusus dengan indikator visual dan teks dinamis saat diarahkan pada kartu proyek.
   - **Form Validation**: Validasi bidang input kontak berbasis Regular Expression (Regex).
   - **Dynamic Tab Switcher**: Navigasi riwayat pembelajaran 5 hari camp berbasis manipulasi DOM.
   - **Skills Accordion**: Komponen daftar keahlian interaktif dengan indikator level.
   - **Portfolio Modal & Filtering**: Penyaringan kategori karya dan popup detail proyek interaktif.

## 🛠️ Tech Stack

- **HTML5**: Struktur semantic & Web Accessibility
- **CSS3**: Layouting (Grid & Flexbox), CSS Variables, Keyframe Animations
- **JavaScript (Vanilla ES6+)**: DOM Manipulation, Event Handling, Regex, LocalStorage API
